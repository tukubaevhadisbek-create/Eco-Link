# Расчёт оценочного сокращения CO₂-экв.

Формула: `CO₂ (кг) = подтверждённый вес (кг) × коэффициент категории (кг CO₂-экв. / кг)`.
Учитываются только операции со статусом COMPLETED. Коэффициент хранится в `material_categories.co2_per_kg`
и редактируется администратором («Категории сырья»).

## Начальные значения в seed — ОРИЕНТИРОВОЧНЫЕ

| Категория | Коэффициент |
|---|---|
| PET-бутылки | 1.5 |
| Другой пластик | 1.2 |
| Картон | 0.9 |
| Макулатура | 0.9 |
| Алюминий | 9.0 |
| Чёрный металл | 1.5 |

**Эти числа не привязаны к проверенному источнику.** Они заданы как порядок величины, чтобы показать механизм.
Перед публичным использованием:

1. Выберите методику (например, EPA WARM, национальные или отраслевые данные) и зафиксируйте версию и ссылку здесь.
2. Обновите коэффициенты в админ-панели.
3. Показатель в интерфейсе везде называется «оценочным» и не является измерением.
