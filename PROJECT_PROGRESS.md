# EcoLink — состояние проекта

Обновлено: 2026-10-21. Точные команды запуска — в `README.md`.

## Готово и проверено

- Слой данных: Drizzle ORM + PostgreSQL, 30 таблиц, индексы, CHECK-ограничения, `numeric` для веса и денег, миграция `drizzle/0000_init.sql`, seed (DEMO, Кара-Суу).
- Авторизация: регистрация (RESIDENT/BUYER), вход, выход, профиль, демо-восстановление, блокировка перебора, серверные сессии, RBAC.
- Житель: заявки (карта, фото, интервалы, цена), отмена, сравнение предложений, коллективные сборы, EcoWallet, PIN-подтверждение, споры, отзывы, уведомления, профиль.
- Скупщик: карта и список (приватные данные скрыты), атомарное принятие, планирование, маршрут через внешние карты, фактический вес + PIN, цены, зоны, транспорт, аналитика, отзывы, подписка (демо), сборы.
- Админ: 17 разделов, споры, модерация, CSV-экспорт агрегатов, журнал действий.
- Главная, EcoImpact (`/impact`), RU/KG (+ EN-каркас), PWA (manifest, SW, офлайн-черновики), AI — честная заглушка.
- Тесты: Vitest 42 ✔, Playwright 15 ✔ (сценарий Enactus 1–17, RBAC, приватность, офлайн, mobile).

## Не реализовано / частично (см. «Известные ограничения» в README)

Платежи, SMS, реальная маршрутизация и оптимизация, AI-распознавание и прогнозы, интерфейс организаций (ответственные, отчёты, соревнования),
проверенные коэффициенты CO₂, идемпотентные ключи офлайн-синхронизации, объектное хранилище фото, rate-limit регистрации.

## Заметки для продолжения

- В среде разработки блокировался `binaries.prisma.sh` → выбран Drizzle (решение пользователя).
- Next.js здесь — версия с изменениями (`proxy.ts` вместо `middleware.ts`, см. `node_modules/next/dist/docs`). Защита ролей сделана в layout/actions, не в proxy.
- `.env.local` не коммитится; пример — `.env.example`.
- E2E изменяют БД: после прогона выполните `npm run db:reset`, чтобы вернуть чистые DEMO-данные.
